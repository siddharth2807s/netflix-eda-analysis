# Netflix Movies & TV Shows - Exploratory Data Analysis

## Overview

This project analyzes the Netflix Movies & TV Shows dataset from Kaggle using Python, Pandas, Matplotlib, and Seaborn.

The objective was to clean the dataset, explore content trends, visualize patterns, and derive meaningful insights.

## Dataset

Source:
https://www.kaggle.com/datasets/shivamb/netflix-shows

Dataset Size:
- 8,807 rows
- 12 columns

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Findings

1. Netflix is predominantly a movie platform.
2. The United States dominates content production.
3. Content additions peaked around 2018–2019.
4. Most Netflix movies are between 80–110 minutes long.
5. TV-MA is the most common rating category.
